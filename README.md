## Features
- Cursor Memory: Remembers the last position of your cursor in your inventory
- Static Custom Position: Set a new fixed position for your cursor in your inventory

📖 Usage Guide

_Cursor Memory_
1. Open your inventory normally
2. Move your cursor anywhere
3. Close and reopen - cursor returns to last position automatically

_Custom static Position_
1. Setting Up Custom Position
2. Open the mod configuration (via Mod Menu)
3. Select Custom Position mode
4. Enable "Record Cursor Position"
5. Open your inventory and move cursor to desired position
6. Close inventory 
7. Disable "Record Cursor Position" in config 
8. Your cursor will now always appear at the recorded position!
